# Research — Upper Limb — MetaCivic Render server

Git-ready Linux x86_64 Unity Dedicated Server repository generated by the
`spatialToUnity Migration Tool`.

## Render

1. Push this whole directory to a GitHub repository.
2. In Render, create a Blueprint from the repository's root `render.yaml`, or
   create a Docker Web Service manually with the Free plan.
3. Do not add a start command or HTTP health-check path. The Dockerfile starts
   `ResearchUpperLimbServer.x86_64` and Render detects its listening port.
4. Wait for the logs to show `FishNet server state: Started`.

Public WebSocket endpoint: `wss://research-upper-limb-serverbuild.onrender.com/`

Render terminates TLS. Bayou listens internally with plain WebSocket on
`0.0.0.0:$PORT`; `PORT` defaults to `10000` on Render. No local FishNet client,
GUI, X server, Cloudflare tunnel, or certificate files are used.

## Local Docker test

```bash
docker build -t metacivic-research-upper-limb .
docker run --rm -e PORT=7773 -p 7773:7773 metacivic-research-upper-limb
```

Local clients connect to `ws://127.0.0.1:7773/`.
